# Release Notes

Curated changelog for each Agent Dock release. These files are the source for three things: the GitHub Releases page, the inline notes in the update dialog, and the **What's New** popup after an update — so they ship embedded in the assembly and work offline.

All pre-releases for a target version share that version's one file (`v0.11.0-beta.2` reads `v0.11.0.md`).

| Version | Highlights |
|---------|------------|
| [v0.11.0](v0.11.0.md) | Remote sessions — drive one machine's agents from another; flicker-free file explorer; services behind interfaces |
| [v0.10.0](v0.10.0.md) | Active Projects group; accent-framed tabs; per-account usage; the account sign-out fix |
| [v0.9.1](v0.9.1.md) | Image attachments; send queue; live subagent visibility; open repo in browser |
| [v0.9.0](v0.9.0.md) | Settings dialogs; tab groups; scheduled messages; virtualized chat; clickable links |
| [v0.8.0](v0.8.0.md) | Sound notifications; plan usage indicator; custom project names; slash-command autocomplete |
| [v0.7.0](v0.7.0.md) | Theme-aware markdown rendering; file preview close button |
| [v0.6.0](v0.6.0.md) | Branch switcher; slash commands and prompt menu; multiline chat input |

---

**Release notes are not the manual.** They say what changed; the [topic pages](../features.md) say how to use it. A pull request that adds a user-facing feature should update both.
