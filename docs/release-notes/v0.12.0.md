# v0.12.0

## Autopilot: A Toolbar On The Repo You're Already Looking At

Autopilot used to live entirely behind **Settings → Set Mode**, with one shared prompt for every
managed session and a session picker that didn't scale past a handful of open repos.

- **Every project now has its own toolbar**, above its panels, with an autopilot control at the
  right-hand end. Click it to add or remove that one repo from the schedule, see its live status
  (scheduled, active, parked), and edit its nudge text — without opening the Set Mode menu
- **Per-project prompts.** Each repo keeps its own nudge text, saved the moment you leave the box,
  independently of whether that project is on the roster or autopilot is armed at all. **Reset to
  default** clears an override back to the built-in prompt. The schedule window itself (start,
  finish, repeat) is still set in one place — the Autopilot dialog — so there's exactly one
  surface that teaches those two time fields
- **A small marker on the tab** (✈) once a project is on the roster — bright while it's actually
  being nudged right now, dim otherwise. Hover for the same verdict the toolbar shows
- **The Autopilot dialog scales past a handful of repos.** Active sessions are listed first, ahead
  of everything that isn't running, and a filter box above the list narrows it by name
- The toolbar also starts and stops the session, shows the send queue and any scheduled message at
  a glance, and quick-toggles which panels are on screen for that project

## Accounts: Reorder The List

Accounts showed up in whatever order they were first added, with no way to change it short of
removing and re-adding one.

- **Drag an account to a new position** in the Accounts dialog. The new order is what every other
  account surface follows — the toolbar usage counter, its session-time dropdown, and the
  per-session account picker — since all three just read the same ordered list

## Fixes

- **The Active Projects limit could never actually reach the number on the box.** The field was
  silently capped at two typed digits, and the stored value itself topped out at 20 — so running
  more sessions than that left the rest with no way to be shown, scrollable or otherwise. The limit
  now goes up to 500, and the project tab row scrolls through however many that lets through, the
  same way it already does everywhere else
